Trading stats for any wallet on Pacifica

Paste a Solana wallet address — the site queries the public Pacifica API directly and shows the account equity and balance, PnL, volume, fees, open positions with liquidation prices, funding, deposits and withdrawals, orders, vaults and a fill analysis. No key and no sign-in are needed; the API gives 100 credits per minute to an IP, so a long history loads in steps and the page says when it waits.

Unofficial project, not affiliated with Pacifica. Data comes from the public API GET https://api.pacifica.fi/api/v1; it may lag or contain exchange errors.

This site connects to the Pacifica API

This site reads data directly from the public Pacifica API (api.pacifica.fi), from your browser and your IP address.

The API gives each IP a limited number of requests per minute. A long trade history therefore loads in steps and the page waits when the limit is reached; if you open many wallets or refresh the page very often, Pacifica may refuse requests for a while. The block usually goes away after a few minutes.

This is an unofficial site, not affiliated with Pacifica.
