This site connects to the Lighter Robinhood API

This site reads data directly from the public Lighter Robinhood API (api.rh.lighter.xyz), from your browser and your IP address.

If you open many wallets in a short time or refresh the page very often, the request limit can be exceeded and the API may temporarily refuse requests from your IP: the page then shows no data or an error. This usually goes away after a few minutes.
